# SPACE ARENA: оверлей клубного ПК

`Start.bat` готовит окружение, устанавливает зависимости из `requirements.txt` и открывает баннер. Если подходящего 64-битного Python с tkinter нет, сценарий скачивает официальный Python 3.14 для Windows x64, проверяет SHA-256 и устанавливает его в профиль пользователя. Для первой загрузки нужен интернет. `Install.bat` выполняет тот же запуск и дополнительно регистрирует автозапуск. При первом запуске нужно ввести адрес сервера и одноразовый код подключения из админки. После настройки агент хранит секрет устройства в DPAPI текущего пользователя Windows.

При обновлении с версии на WebView2 завершите старый `pythonw.exe` с аргументом `agent.py`, замените файлы агента и снова запустите `Install.bat`, чтобы установить Qt WebEngine. Сохранённое подключение используется при запуске.

Баннер открывается справа сверху основного экрана: левая граница — 51% ширины, правая — с отступом 2,1%, верхняя — с отступом 8,3%, нижняя — на 59% высоты. На клубных обоях это выравнивает его по логотипу, OTHER и нижней рамке GAMES. Окно имеет рамку внутри баннера, располагается ниже обычных окон, не имеет кнопки на панели задач и не создаёт отдельного окна управления. Окно называется Space Arena Banner. В деталях Диспетчера задач процесс Python можно опознать по `agent.py` в столбце «Командная строка». Отдельный процесс PowerShell (`WatchdogHost.ps1`) остаётся запущенным при завершении всей группы Python и восстанавливает баннер. `watchdog.py` следит за процессами баннера и завершает их при штатном выключении.

`Stop.bat` выключает баннер и автоматическое восстановление. Выключение сохраняется после перезагрузки. `Start.bat` включает баннер и восстановление. Для повторной настройки запустите `Stop.bat`, затем `Configure.bat`. При обновлении со старого автозапуска выполните `Install.bat`, чтобы ярлык запускал `WatchdogHost.ps1`.

Временная ссылка QR доступна баннеру через локальный HTTP-сервер `127.0.0.1` и обновляется автоматически. Клик по баннеру открывает заказ во внешнем браузере. При блокировке стола или ПК QR пропадает. Для телефона адрес сервера из настройки агента должен быть доступен с его сети или мобильного интернета.

После «Завершить визит» на странице заказов сервер отзывает старый QR. Агент получает новый при ближайшей проверке связи, обычно в течение 30 секунд. После обновления `agent.py` перезапустите агент, чтобы включить эту проверку.

Заставка играет при запуске, после разблокировки Windows и при возврате на рабочий стол после выгрузки баннера. В финальном кадре логотип плавно покачивается, а орбита меняет наклон. Через 5 секунд полноэкранного режима на экране с баннером агент завершает заставку и приостанавливает плавное движение. Через минуту он скрывает баннер и выгружает его страницу. При выходе из полноэкранного режима до выгрузки движение возобновляется в текущем кадре.
