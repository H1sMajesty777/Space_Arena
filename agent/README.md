# SPACE ARENA: оверлей клубного ПК

`Install.bat` устанавливает агент, регистрирует автозапуск и открывает баннер. При первом запуске нужно ввести адрес сервера и одноразовый код подключения из админки. После настройки агент хранит секрет устройства в DPAPI текущего пользователя Windows.

При обновлении с версии на WebView2 завершите старый `pythonw.exe` с аргументом `agent.py`, замените файлы агента и снова запустите `Install.bat`, чтобы установить Qt WebEngine. Сохранённое подключение используется при запуске.

Баннер открывается справа сверху основного экрана: левая граница — 51% ширины, правая — с отступом 2,1%, верхняя — с отступом 8,3%, нижняя — на 59% высоты. На клубных обоях это выравнивает его по логотипу, OTHER и нижней рамке GAMES. Окно имеет рамку внутри баннера, располагается ниже обычных окон, не имеет кнопки на панели задач и не создаёт отдельного окна управления. При запуске нового агента поверх уже работающего второй экземпляр не открывается. Чтобы остановить агент, завершите `pythonw.exe` с аргументом `agent.py` в диспетчере задач; для отключения автозапуска удалите ярлык `SpaceArena` из папки автозагрузки Windows.

Временная ссылка QR доступна баннеру через локальный HTTP-сервер `127.0.0.1` и обновляется автоматически. Клик по баннеру открывает заказ во внешнем браузере. При блокировке стола или ПК QR пропадает. Для телефона адрес сервера из настройки агента должен быть доступен с его сети или мобильного интернета.

После «Завершить визит» на странице заказов сервер отзывает старый QR. Агент получает новый при ближайшей проверке связи, обычно в течение 30 секунд. После обновления `agent.py` перезапустите агент, чтобы включить эту проверку.

Анимация проигрывается при запуске агента и после каждой разблокировки его сеанса Windows. После каждого показа баннер остаётся на финальном кадре. Если активное окно закрывает всю область баннера в течение 5 секунд, агент сразу переводит его на финальный кадр. Оверлей остаётся под обычными окнами, а финал виден, как только они освобождают область.
